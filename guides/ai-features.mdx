Mutasib includes a suite of AI-powered tools that help you make smarter stocking decisions and get instant answers about your business — in plain Arabic or English. Whether you want a demand forecast for a single product, a full reorder plan for your entire catalogue, or a conversational assistant that can actually execute changes on your behalf, it is all available through the AI endpoints.

## M.AI conversational assistant

M.AI is Mutasib's flagship AI agent. Unlike a simple chatbot, M.AI has access to real tools — it can look up your inventory, record sales, update stock levels, and answer questions about your business data, all within a single conversation turn.

Send messages to `POST /api/v1/shops/{shop_id}/ai/mutasib` with an optional `conversation_history` array to maintain context across turns.

<Tip>
  Include the full `conversation_history` in every request. The API is stateless — each call is independent, and omitting the history causes M.AI to lose context about earlier turns in the conversation.
</Tip>

<CodeGroup>
```bash English (cURL)
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/mutasib \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "How many units of olive oil do we have left, and should I reorder?",
    "conversation_history": []
  }'
```

```bash Arabic (cURL)
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/mutasib \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "كم وحدة من زيت الزيتون لدينا؟ هل يجب أن أعيد الطلب؟",
    "conversation_history": []
  }'
```

```python Python
import requests

history = []

def chat(message: str) -> str:
    response = requests.post(
        "https://api.mutasib.com/api/v1/shops/42/ai/mutasib",
        headers={"Authorization": "Bearer <your_token>"},
        json={"message": message, "conversation_history": history},
    )
    data = response.json()
    # Append both turns to history for the next request
    history.append({"role": "user", "content": message})
    history.append({"role": "assistant", "content": data["response"]})
    return data["response"]

print(chat("What were my top 5 selling products this week?"))
```
</CodeGroup>

An example response:

```json
{
  "response": "You currently have 14 units of olive oil (SKU: OO-500ML) in stock. Based on your sales velocity over the past 30 days, that gives you roughly 6 days of cover. I'd recommend placing a reorder soon — would you like me to create a reorder suggestion for you?"
}
```

M.AI automatically detects the language of your message and replies in kind. You do not need to set a language flag.

## Demand forecasting

Use the predict endpoint to get a demand forecast for a specific product. The forecast is based on your shop's historical sales data and accounts for trends and seasonality.

Send `POST /api/v1/shops/{shop_id}/ai/predict` with the product ID:

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/predict \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{"product_id": 17}'
```

The response includes a plain-language `reasoning` field explaining the factors behind the forecast:

```json
{
  "product_name": "Olive Oil 500ml",
  "prediction": 48,
  "confidence": 0.82,
  "reasoning": "Sales have averaged 45 units per month over the past 90 days, with a slight upward trend. Confidence is high due to consistent demand patterns with low variance."
}
```

The `confidence` score ranges from `0` to `1`. Scores above `0.7` indicate a reliable forecast; lower scores suggest limited sales history for this product.

## Reorder suggestions

### Single-product reorder

To get a reorder recommendation for one product, send `POST /api/v1/shops/{shop_id}/ai/reorder` with the product ID:

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/reorder \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{"product_id": 17}'
```

```json
{
  "product_name": "Olive Oil 500ml",
  "suggested_order": 60,
  "urgency": "high",
  "reasoning": "Current stock of 14 units covers approximately 6 days at the current sales rate. Lead time from your supplier is typically 3–4 days, leaving very little buffer. Ordering 60 units will cover the next 40 days."
}
```

The `urgency` field is one of `"low"`, `"medium"`, or `"high"`, giving you a quick signal for prioritisation.

### Batch reorder for all low-stock products

To get recommendations across your entire catalogue at once, call the batch-reorder endpoint with an empty body:

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/batch-reorder \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{}'
```

The response includes a `recommendations` array (one entry per flagged product) and a `summary` string with an overview:

```json
{
  "summary": "8 products require attention: 3 are critically low (reorder immediately), 5 are running low within the next 7 days.",
  "recommendations": [
    {
      "product_id": 17,
      "product_name": "Olive Oil 500ml",
      "suggested_order": 60,
      "urgency": "high",
      "reasoning": "..."
    },
    {
      "product_id": 23,
      "product_name": "Labneh 500g",
      "suggested_order": 24,
      "urgency": "medium",
      "reasoning": "..."
    }
  ]
}
```

### Applying recommendations

Once you have reviewed the batch-reorder output, you can instruct Mutasib to apply the suggestions for a set of products in one call. Send `POST /api/v1/shops/{shop_id}/ai/apply-recommendations` with the product IDs you want to action:

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/apply-recommendations \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{"product_ids": [17, 23]}'
```

This creates pending purchase orders or reorder records for the selected products using the quantities suggested in the most recent batch-reorder result.

## General AI chat

The `/ai/chat` endpoint provides a lighter-weight conversational interface. Unlike M.AI, it does not have access to tools and cannot execute changes — it answers questions based on the context you provide and general business knowledge.

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/chat \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "What is the best way to manage shrinkage in a small grocery shop?",
    "history": [],
    "language": "en"
  }'
```

Pass `"language": "ar"` to receive a response in Arabic. Unlike M.AI, the `/ai/chat` endpoint does not auto-detect language — you must specify it explicitly. The default is `"en"`.
