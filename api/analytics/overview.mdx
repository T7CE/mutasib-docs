The analytics endpoints give you a complete picture of your shop's financial performance — revenue trends over time, gross vs. net profit, your best-selling products, and how different product categories contribute to total revenue. You can also compare any period to the one that preceded it to spot growth or decline at a glance.

<Note>
  Analytics require a **Starter or Pro** plan. Shops on the Free plan receive only the basic today's-stats endpoint available through the [Sales API](/api/sales/overview).
</Note>

## Shop Analytics

Fetch a full analytics report for a shop covering a rolling window of days you specify.

**`GET /api/v1/shops/{shop_id}/analytics`**

<ParamField query="days" type="integer">
  Number of days to include in the analysis window, counting back from today. Defaults to `30`. For example, `days=7` gives you the last seven days.
</ParamField>

```bash
curl "https://api.mutasib.com/api/v1/shops/42/analytics?days=30" \
  -H "Authorization: Bearer <token>"
```

### Response — `AnalyticsOut`

<ResponseField name="shop_name" type="string">
  Display name of the shop.
</ResponseField>
<ResponseField name="period_days" type="integer">
  The number of days this report covers, as requested.
</ResponseField>
<ResponseField name="total_revenue" type="string">
  Gross revenue (sum of all sale totals) for the period, returned as a decimal string.
</ResponseField>
<ResponseField name="total_cost" type="string">
  Total cost of goods sold for the period, returned as a decimal string. Present only if cost prices are configured.
</ResponseField>
<ResponseField name="net_revenue" type="string">
  `total_revenue − total_cost`, returned as a decimal string. Represents gross profit for the period.
</ResponseField>
<ResponseField name="total_sales_count" type="integer">
  Total number of individual transactions recorded in the period.
</ResponseField>
<ResponseField name="avg_order_value" type="string">
  Average value per transaction (`total_revenue / total_sales_count`), returned as a decimal string.
</ResponseField>
<ResponseField name="revenue_trend" type="array">
  Day-by-day revenue breakdown for the period.

  <Expandable title="revenue_trend item properties">
    <ResponseField name="date" type="string">
      ISO 8601 date string (e.g. `"2024-01-15"`).
    </ResponseField>
    <ResponseField name="revenue" type="number">
      Total revenue recorded on that date.
    </ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="top_products" type="array">
  The best-performing products by revenue for the period, sorted descending.

  <Expandable title="top_products item properties">
    <ResponseField name="product_name" type="string">
      Name of the product.
    </ResponseField>
    <ResponseField name="total_sold" type="integer">
      Total units sold in the period.
    </ResponseField>
    <ResponseField name="revenue" type="number">
      Total revenue generated by this product.
    </ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="category_breakdown" type="array">
  Revenue split by product category.

  <Expandable title="category_breakdown item properties">
    <ResponseField name="category" type="string">
      Category name.
    </ResponseField>
    <ResponseField name="revenue" type="number">
      Total revenue from this category.
    </ResponseField>
    <ResponseField name="percentage" type="number">
      This category's share of total revenue, as a percentage (0–100).
    </ResponseField>
  </Expandable>
</ResponseField>
<ResponseField name="comparison_previous" type="object">
  Compares the current period to the immediately preceding period of the same length.

  <Expandable title="comparison_previous properties">
    <ResponseField name="revenue_change_pct" type="number">
      Percentage change in revenue vs. the prior period. Positive means growth.
    </ResponseField>
    <ResponseField name="sales_count_change_pct" type="number">
      Percentage change in transaction count vs. the prior period.
    </ResponseField>
  </Expandable>
</ResponseField>

## Suppliers

Supplier records let you link products to their source and keep contact details in one place. All supplier endpoints are scoped to a shop.

<Note>
  Supplier management is a **Pro plan** feature.
</Note>

### List suppliers

**`GET /api/v1/shops/{shop_id}/suppliers`**

```bash
curl https://api.mutasib.com/api/v1/shops/42/suppliers \
  -H "Authorization: Bearer <token>"
```

Returns an array of `SupplierOut` objects.

### Create a supplier

**`POST /api/v1/shops/{shop_id}/suppliers`**

<ParamField body="name" type="string" required>
  Supplier's business or trading name.
</ParamField>
<ParamField body="contact_name" type="string">
  Name of the primary contact person at the supplier.
</ParamField>
<ParamField body="phone" type="string">
  Supplier contact phone number.
</ParamField>
<ParamField body="email" type="string">
  Supplier contact email address.
</ParamField>
<ParamField body="address" type="string">
  Physical or mailing address for the supplier.
</ParamField>
<ParamField body="notes" type="string">
  Free-text notes about this supplier (e.g. payment terms, delivery schedule).
</ParamField>

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/42/suppliers \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Al-Fajr Distributors",
    "contact_name": "Khaled Mansour",
    "phone": "+213551234567",
    "email": "khaled@alfajr.dz",
    "address": "Zone Industrielle, Blida",
    "notes": "Delivers every Monday. Net-30 payment terms."
  }'
```

### Get a supplier

**`GET /api/v1/shops/{shop_id}/suppliers/{supplier_id}`**

```bash
curl https://api.mutasib.com/api/v1/shops/42/suppliers/9 \
  -H "Authorization: Bearer <token>"
```

### Update a supplier

**`PATCH /api/v1/shops/{shop_id}/suppliers/{supplier_id}`**

Send only the fields you want to change. Accepts the same fields as `SupplierIn`.

```bash
curl -X PATCH https://api.mutasib.com/api/v1/shops/42/suppliers/9 \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{ "phone": "+213559876543" }'
```

### Delete a supplier

**`DELETE /api/v1/shops/{shop_id}/suppliers/{supplier_id}`**

```bash
curl -X DELETE https://api.mutasib.com/api/v1/shops/42/suppliers/9 \
  -H "Authorization: Bearer <token>"
```

Returns `204 No Content` on success.

### `SupplierOut` fields

<ResponseField name="id" type="integer">

</ResponseField>
<ResponseField name="name" type="string">
  Supplier business name.
</ResponseField>
<ResponseField name="contact_name" type="string">
  Primary contact person, if set.
</ResponseField>
<ResponseField name="phone" type="string">
  Contact phone number, if set.
</ResponseField>
<ResponseField name="email" type="string">
  Contact email address, if set.
</ResponseField>
<ResponseField name="address" type="string">
  Supplier address, if set.
</ResponseField>
<ResponseField name="notes" type="string">
  Free-text notes about the supplier.
</ResponseField>
<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the supplier was added.
</ResponseField>
