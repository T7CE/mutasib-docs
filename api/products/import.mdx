The bulk import endpoint lets you add dozens or hundreds of products to your shop in a single API call by uploading a prepared CSV or Excel spreadsheet. This is especially useful when migrating from another system, launching a new shop, or performing large seasonal restocks. Once the upload is processed, Mutasib returns a structured report showing how many products were successfully imported and which rows (if any) contained errors.

---

## Import products from a file

<br />

`POST /api/v1/shops/import`

Accepts a CSV (`.csv`) or Excel (`.xlsx`) file containing product data and creates a product record in the specified shop for each valid row. Rows that fail validation are skipped and reported in the response — they do not block the rest of the import.

The request must be sent as `Content-Type: multipart/form-data`.

### Form fields

<ParamField body="file" type="file" required>
  The CSV or Excel file to import. Must be a `.csv` or `.xlsx` file encoded in UTF-8. Maximum file size is 10 MB.
</ParamField>

<ParamField body="shop_id" type="integer" required>
  The ID of the shop to import products into. You must be the owner of this shop.
</ParamField>

---

## Expected file columns

Your spreadsheet must include a header row with the column names listed below. Columns marked as **Required** must be present and non-empty. Optional columns can be omitted entirely or left blank to use the default value.

| Column | Type | Required | Default | Description |
|--------|------|----------|---------|-------------|
| `name` | string | ✅ Yes | — | Product display name. |
| `price` | number | ✅ Yes | — | Selling price. Must be ≥ 0. |
| `barcode` | string | No | `""` | Product barcode (EAN, UPC, or custom). Duplicate barcodes within the same shop are skipped. |
| `cost` | number | No | `0` | Purchase or production cost. |
| `stock` | integer | No | `0` | Initial stock quantity. |
| `low_stock_threshold` | integer | No | `10` | Stock level at which a low-stock alert fires. |
| `unit` | string | No | `"piece"` | Unit of measurement (e.g., `piece`, `kg`, `litre`, `box`). |
| `category` | string | No | — | Category name. If a category with this name exists in the shop, the product is assigned to it. If not, a new top-level category is created automatically. |
| `description` | string | No | `""` | Product description. |

## curl example

The following example uploads a file named `products.csv` for shop `42`:

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/import \
  -H "Authorization: Bearer <your_token>" \
  -F "shop_id=42" \
  -F "file=@products.csv"
```

For an Excel file, simply point to your `.xlsx` file instead:

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/import \
  -H "Authorization: Bearer <your_token>" \
  -F "shop_id=42" \
  -F "file=@products.xlsx"
```

## Response

A successful upload returns `200 OK` with a JSON object summarising the import results.

<ResponseField name="imported" type="integer">
  The number of product rows that were successfully created.
</ResponseField>

<ResponseField name="failed" type="integer">
  The number of rows that were skipped due to validation errors.
</ResponseField>

<ResponseField name="errors" type="array">
  A list of error objects describing each failed row.
  <Expandable title="properties">
    <ResponseField name="row" type="integer">
      The 1-based row number in the file where the error occurred (not counting the header row).
    </ResponseField>
    <ResponseField name="field" type="string">
      The column name that caused the error.
    </ResponseField>
    <ResponseField name="message" type="string">
      A human-readable description of the validation error.
    </ResponseField>
  </Expandable>
</ResponseField>

Example response:

```json
{
  "imported": 143,
  "failed": 2,
  "errors": [
    {
      "row": 12,
      "field": "price",
      "message": "Price must be a non-negative number. Got: \"N/A\"."
    },
    {
      "row": 57,
      "field": "name",
      "message": "Product name is required and cannot be blank."
    }
  ]
}
```

<Note>
  Save your spreadsheet in **UTF-8** encoding before uploading. Excel files may default to a regional encoding that corrupts Arabic product names during import. In Excel, choose **Save As → CSV UTF-8 (Comma delimited)** to ensure Arabic characters are preserved correctly.
</Note>

<Tip>
  Download the official Mutasib import template from your shop's dashboard to get a correctly formatted file with all supported columns pre-filled with example data. Additionally, populate the `barcode` column wherever possible — if a product with the same barcode already exists in your shop, the import skips that row instead of creating a duplicate, making re-imports safe to run multiple times.
</Tip>
