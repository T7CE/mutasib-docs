All AI endpoints support both Arabic and English.

## Demand Prediction

Predict future demand for a specific product based on its historical sales patterns and seasonality signals.

**`POST /api/v1/shops/{shop_id}/ai/predict`**

<ParamField body="product_id" type="integer" required>
  The ID of the product you want to forecast demand for.
</ParamField>

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/predict \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{ "product_id": 101 }'
```

### Response — `PredictDemandOut`

<ResponseField name="product_name" type="string">
  Name of the product being analyzed.
</ResponseField>
<ResponseField name="prediction" type="string">
  A human-readable demand forecast (e.g. `"High demand expected next week due to weekend patterns"`).
</ResponseField>
<ResponseField name="confidence" type="number">
  A float between `0.0` and `1.0` indicating the model's confidence in the prediction.
</ResponseField>
<ResponseField name="reasoning" type="string">
  Explanation of the factors that drove the prediction.
</ResponseField>

**Sample response**

```json
{
  "product_name": "Whole Milk 1L",
  "prediction": "Demand expected to rise 18% over the next 7 days",
  "confidence": 0.82,
  "reasoning": "Sales of this product spike consistently on Thursdays and Fridays based on 90 days of historical data. A local event this weekend may further increase demand."
}
```

## Reorder Suggestion (Single Product)

Get a suggested reorder quantity and urgency rating for one product based on current stock, sales velocity, and lead time.

**`POST /api/v1/shops/{shop_id}/ai/reorder`**

<ParamField body="product_id" type="integer" required>
  The ID of the product to generate a reorder suggestion for.
</ParamField>

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/reorder \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{ "product_id": 205 }'
```

### Response — `ReorderOut`

<ResponseField name="product_name" type="string">
  Name of the product.
</ResponseField>
<ResponseField name="suggested_order" type="integer">
  Recommended quantity to order to cover forecasted demand.
</ResponseField>
<ResponseField name="urgency" type="string">
  How urgently the reorder is needed. One of `low`, `medium`, `high`, or `critical`.
</ResponseField>
<ResponseField name="reasoning" type="string">
  Explanation for the suggested quantity and urgency level.
</ResponseField>

**Urgency levels**

| Value | Meaning |
|---|---|
| `low` | Stock is healthy; order when convenient. |
| `medium` | Stock will run low within 7–14 days at current velocity. |
| `high` | Stock will run out within 3–7 days. Order soon. |
| `critical` | Stock is at or below threshold. Order immediately. |

## Batch Reorder

Generate reorder suggestions for **all** low-stock products in a shop at once. No request body is needed — Mutasib scans your inventory automatically.

**`POST /api/v1/shops/{shop_id}/ai/batch-reorder`**

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/batch-reorder \
  -H "Authorization: Bearer <token>"
```

### Response — `BatchReorderOut`

<ResponseField name="recommendations" type="array">
  An array of `ReorderOut` objects, one per product that needs restocking.
</ResponseField>
<ResponseField name="summary" type="string">
  A human-readable summary of the batch analysis (e.g. `"12 products need reordering; 3 are critical"`).
</ResponseField>

## Apply Recommendations

Automatically apply the suggested reorder quantities as inventory adjustments for a list of products. This endpoint creates `purchase` movement records for each product.

**`POST /api/v1/shops/{shop_id}/ai/apply-recommendations`**

<ParamField body="product_ids" type="array" required>
  List of product IDs for which to apply the AI-suggested reorder quantities as inventory adjustments.
</ParamField>

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/apply-recommendations \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{ "product_ids": [101, 205, 307] }'
```

Returns a summary of which adjustments were applied successfully.

## M.AI Conversational Agent

M.AI is Mutasib's intelligent shop assistant. Unlike the general chat endpoint, M.AI has access to your shop's live data and can execute actions on your behalf — checking real-time stock, fetching recent sales figures, searching your product catalog, or updating inventory quantities. M.AI works fluently in both Arabic and English.

**`POST /api/v1/shops/{shop_id}/ai/mutasib`**

<ParamField body="message" type="string" required>
  Your message or question to M.AI.
</ParamField>
<ParamField body="conversation_history" type="array">
  Previous turns in the conversation, enabling multi-turn dialogue. Each entry is an object with `role` (`user` or `assistant`) and `content` fields. Pass an empty array to start a new conversation.
</ParamField>

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/mutasib \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "How many units of Whole Milk do we have left?",
    "conversation_history": []
  }'
```

**Example English exchange**

```json
// Request
{
  "message": "Which products are running low and need reordering today?",
  "conversation_history": []
}

// Response
{
  "response": "You currently have 4 products below their low-stock threshold: Bottled Water 500ml (7 units, threshold 20), Cooking Oil 1L (3 units, threshold 15), Bread Loaf (2 units, threshold 10), and Sugar 1kg (5 units, threshold 25). I'd recommend placing an order for all four today — Bread Loaf and Cooking Oil are the most urgent."
}
```

**Example Arabic exchange**

```json
// Request
{
  "message": "كم كانت مبيعات اليوم؟",
  "conversation_history": []
}

// Response
{
  "response": "مبيعات اليوم بلغت 3,240 دج موزّعة على 47 عملية بيع، بمتوسط قيمة طلب 68.94 دج. أعلى المنتجات مبيعًا كان الحليب كامل الدسم بـ 38 وحدة."
}
```

## General AI Chat

The chat endpoint provides conversational AI assistance without tool execution — it answers questions, explains concepts, and gives advice, but does not read from or write to your shop's data. Use this for general retail and business queries.

**`POST /api/v1/shops/{shop_id}/ai/chat`**

<ParamField body="message" type="string" required>
  Your message to the AI.
</ParamField>
<ParamField body="history" type="array">
  Previous conversation turns for multi-turn context. Each entry has `role` and `content` fields.
</ParamField>
<ParamField body="language" type="string">
  Response language. Defaults to `en`. Pass `ar` for Arabic responses.
</ParamField>

```bash
curl -X POST https://api.mutasib.com/api/v1/shops/42/ai/chat \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "What is a good strategy for pricing perishable goods?",
    "history": [],
    "language": "en"
  }'
```
