Mutasib supports two types of two-factor authentication (2FA): **TOTP** (Time-based One-Time Password), which works with any standards-compliant authenticator app such as Google Authenticator or Authy, and **email-based codes**, which send a one-time code to your registered email address. You can enable one method at a time per account.

---

## TOTP Two-Factor Authentication

TOTP 2FA ties your account to a time-sensitive code generated by an authenticator app. Setup is a three-step process: generate the secret, scan it into your app, and then verify a live code to confirm the link.

### Step 1 — Generate the TOTP Secret

Initiate the setup by calling the setup endpoint. This requires a valid Bearer token, so you must be logged in already.

```
GET /api/v1/auth/2fa/setup
```

```bash
curl --request GET \
  --url https://api.mutasib.com/api/v1/auth/2fa/setup \
  --header 'Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...'
```

**Response — 200 OK**

```json
{
  "secret": "JBSWY3DPEHPK3PXP",
  "qr_code_uri": "otpauth://totp/Mutasib:sara@example.com?secret=JBSWY3DPEHPK3PXP&issuer=Mutasib"
}
```

Scan the `qr_code_uri` with your authenticator app, or manually enter the `secret`. Once scanned, the app begins generating six-digit codes that rotate every 30 seconds.

### Step 2 — Verify and Enable TOTP

Confirm that your authenticator app is working correctly by submitting a live code. This call both validates the code and activates TOTP 2FA on your account.

```
POST /api/v1/auth/2fa/verify
```

<ParamField body="code" type="string" required>
  The current six-digit TOTP code from your authenticator app.
</ParamField>

```bash
curl --request POST \
  --url https://api.mutasib.com/api/v1/auth/2fa/verify \
  --header 'Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...' \
  --header 'Content-Type: application/json' \
  --data '{
    "code": "123456"
  }'
```

**Response — 200 OK**

```json
{
  "message": "TOTP 2FA has been successfully enabled on your account."
}
```

### Step 3 — Login with TOTP

Once TOTP is enabled, every login requires the current code from your authenticator app. Use the dedicated 2FA login endpoint instead of the standard login.

```
POST /api/v1/auth/login-2fa
```

<ParamField body="email" type="string" required>
  Your account email address.
</ParamField>

<ParamField body="password" type="string" required>
  Your account password.
</ParamField>

<ParamField body="code" type="string" required>
  The current six-digit TOTP code from your authenticator app.
</ParamField>

```bash
curl --request POST \
  --url https://api.mutasib.com/api/v1/auth/login-2fa \
  --header 'Content-Type: application/json' \
  --data '{
    "email": "sara@example.com",
    "password": "S3cur3P@ssw0rd!",
    "code": "123456"
  }'
```

**Response — 200 OK**

```json
{
  "access": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}
```

### Disable TOTP

To turn off TOTP 2FA, submit a valid code from your authenticator app to confirm intent.

```
POST /api/v1/auth/2fa/disable
```

<ParamField body="code" type="string" required>
  The current six-digit TOTP code from your authenticator app, confirming that you still have access.
</ParamField>

```bash
curl --request POST \
  --url https://api.mutasib.com/api/v1/auth/2fa/disable \
  --header 'Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...' \
  --header 'Content-Type: application/json' \
  --data '{
    "code": "654321"
  }'
```

**Response — 200 OK**

```json
{
  "message": "TOTP 2FA has been disabled."
}
```

## Email Two-Factor Authentication

Email 2FA sends a one-time code to your registered email address each time you log in. It requires no external app — only access to your inbox.

### Enable Email 2FA

Call the enable endpoint with a valid Bearer token. No request body is needed.

```
POST /api/v1/auth/2fa/email/enable
```

```bash
curl --request POST \
  --url https://api.mutasib.com/api/v1/auth/2fa/email/enable \
  --header 'Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...'
```

**Response — 200 OK**

```json
{
  "message": "Email 2FA has been enabled. A one-time code will be sent to your email address each time you log in."
}
```

### Disable Email 2FA

Call the disable endpoint with a valid Bearer token. No request body is needed.

```
POST /api/v1/auth/2fa/email/disable
```

```bash
curl --request POST \
  --url https://api.mutasib.com/api/v1/auth/2fa/email/disable \
  --header 'Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...'
```

**Response — 200 OK**

```json
{
  "message": "Email 2FA has been disabled."
}
```

### Login Flow with Email 2FA

When email 2FA is active on your account, the standard login endpoint returns `202 Accepted` and dispatches a one-time code to your email. Complete the flow in a second request.

**Step 1 — Call the standard login endpoint**

```bash
curl --request POST \
  --url https://api.mutasib.com/api/v1/auth/login \
  --header 'Content-Type: application/json' \
  --data '{
    "email": "sara@example.com",
    "password": "S3cur3P@ssw0rd!"
  }'
```

```json
{
  "message": "A verification code has been sent to your email address. Please submit it to complete login."
}
```

**Step 2 — Submit the emailed code**

```
POST /api/v1/auth/login-email-2fa
```

<ParamField body="email" type="string" required>
  The email address associated with the account you are logging into.
</ParamField>

<ParamField body="code" type="string" required>
  The six-digit one-time code sent to your email address.
</ParamField>

```bash
curl --request POST \
  --url https://api.mutasib.com/api/v1/auth/login-email-2fa \
  --header 'Content-Type: application/json' \
  --data '{
    "email": "sara@example.com",
    "code": "847291"
  }'
```

**Response — 200 OK**

```json
{
  "access": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "refresh": "eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}
```

## Check 2FA Status

Retrieve the current 2FA configuration for the authenticated user at any time. This endpoint requires a valid Bearer token.

```
GET /api/v1/auth/2fa/status
```

```bash
curl --request GET \
  --url https://api.mutasib.com/api/v1/auth/2fa/status \
  --header 'Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...'
```

**Response — 200 OK**

```json
{
  "totp_enabled": true,
  "email_2fa_enabled": false
}
```

<ResponseField name="totp_enabled" type="boolean">
  `true` if TOTP 2FA is currently active on the account.
</ResponseField>

<ResponseField name="email_2fa_enabled" type="boolean">
  `true` if email-based 2FA is currently active on the account.
</ResponseField>

---

<Warning>
  If you lose access to your authenticator app while TOTP 2FA is enabled, you will be locked out of your account. Save your TOTP secret in a secure password manager at setup time so you can re-configure a new device if needed. If you are already locked out, contact Mutasib support to initiate a verified account recovery process.
</Warning>
