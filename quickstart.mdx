title: "Quick Start: Make Your First Mutasib API Call in Minutes"
sidebarTitle: "Quick Start"

This guide walks you through the five essential steps to go from zero to a working Mutasib integration. By the end you will have a verified account, a live shop, a product in your catalog, and your first recorded sale — with real API calls you can run right now. Every subsequent API feature (inventory alerts, analytics, multi-cashier flows) builds on exactly this foundation.

<Steps>
  <Step title="Register an account">
    Send a `POST` request to `/api/v1/auth/register` with your email, a username, and a password. The `role` field defaults to `shopowner`; pass `cashier` if you are creating a cashier account instead.

    <CodeGroup>
      ```bash curl
      curl -X POST https://api.mutasib.com/api/v1/auth/register \
        -H "Content-Type: application/json" \
        -d '{
          "email": "you@example.com",
          "username": "yourname",
          "password": "Sup3rS3cure!",
          "role": "shopowner"
        }'
      ```

      ```python Python
      import requests

      response = requests.post(
          "https://api.mutasib.com/api/v1/auth/register",
          json={
              "email": "you@example.com",
              "username": "yourname",
              "password": "Sup3rS3cure!",
              "role": "shopowner",
          },
      )
      print(response.json())
      ```

      ```js JavaScript
      const response = await fetch(
        "https://api.mutasib.com/api/v1/auth/register",
        {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({
            email: "you@example.com",
            username: "yourname",
            password: "Sup3rS3cure!",
            role: "shopowner",
          }),
        }
      );
      const data = await response.json();
      console.log(data);
      ```
    </CodeGroup>

    A successful registration returns `201 Created` with a token pair:

    ```json
    {
      "access": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "refresh": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "token_type": "bearer"
    }
    ```

    <Note>
      Mutasib sends a verification email to the address you registered with. You must verify your email before you can log in. Check your inbox (and spam folder) for a message containing your verification link.
    </Note>
  </Step>

  <Step title="Verify your email">
    Click the link in your verification email, or extract the `token` query parameter from it and call the verify endpoint directly. The token is a one-time code tied to your email address.

    <CodeGroup>
      ```bash curl
      curl -X POST \
        "https://api.mutasib.com/api/v1/auth/verify-email?token=YOUR_VERIFICATION_TOKEN"
      ```

      ```python Python
      import requests

      response = requests.post(
          "https://api.mutasib.com/api/v1/auth/verify-email",
          params={"token": "YOUR_VERIFICATION_TOKEN"},
      )
      print(response.json())
      ```

      ```js JavaScript
      const response = await fetch(
        "https://api.mutasib.com/api/v1/auth/verify-email?token=YOUR_VERIFICATION_TOKEN",
        { method: "POST" }
      );
      const data = await response.json();
      console.log(data);
      ```
    </CodeGroup>

    On success the API returns a fresh token pair:

    ```json
    {
      "access": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
      "refresh": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
    }
    ```

    Store both tokens. You will use the `access` token in every subsequent request, and the `refresh` token to renew it when it expires. If you did not receive the email, call `POST /api/v1/auth/resend-verification?email=you@example.com` to request a new one.
  </Step>

  <Step title="Create your shop">
    With a verified account and a valid access token, create your first shop by posting to `/api/v1/shops/`. The `name`, `address`, and `category` fields are required.

    <CodeGroup>
      ```bash curl
      curl -X POST https://api.mutasib.com/api/v1/shops/ \
        -H "Content-Type: application/json" \
        -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
        -d '{
          "name": "Green Leaf Grocery",
          "address": "12 Market Street, Riyadh",
          "category": "grocery",
          "description": "Fresh produce and daily essentials.",
          "phone_number": "+966501234567"
        }'
      ```

      ```python Python
      import requests

      headers = {
          "Authorization": "Bearer YOUR_ACCESS_TOKEN",
          "Content-Type": "application/json",
      }
      payload = {
          "name": "Green Leaf Grocery",
          "address": "12 Market Street, Riyadh",
          "category": "grocery",
          "description": "Fresh produce and daily essentials.",
          "phone_number": "+966501234567",
      }
      response = requests.post(
          "https://api.mutasib.com/api/v1/shops/",
          json=payload,
          headers=headers,
      )
      print(response.json())
      ```

      ```js JavaScript
      const response = await fetch("https://api.mutasib.com/api/v1/shops/", {
        method: "POST",
        headers: {
          "Content-Type": "application/json",
          Authorization: "Bearer YOUR_ACCESS_TOKEN",
        },
        body: JSON.stringify({
          name: "Green Leaf Grocery",
          address: "12 Market Street, Riyadh",
          category: "grocery",
          description: "Fresh produce and daily essentials.",
          phone_number: "+966501234567",
        }),
      });
      const data = await response.json();
      console.log(data);
      ```
    </CodeGroup>

    The response includes your new shop's `id`. Copy it — you need it for every subsequent shop-scoped request.

    ```json
    {
      "id": "shop_01j9xkz3p4qr5t6uvw7yz8abc",
      "owner_id": "usr_01j9xkz3p4qr5t6uvw7yz8xyz",
      "name": "Green Leaf Grocery",
      "address": "12 Market Street, Riyadh",
      "category": "grocery",
      "description": "Fresh produce and daily essentials.",
      "phone_number": "+966501234567",
      "is_active": true,
      "is_approved": false,
      "plan": "free",
      "max_cashiers": 1,
      "is_visible_in_search": false,
      "created_at": "2024-11-01T10:00:00Z",
      "updated_at": "2024-11-01T10:00:00Z"
    }
    ```

    <Info>
      New shops start with `is_approved: false`. Your shop is fully functional for API use immediately; the approval flag affects public discoverability in Mutasib's search directory.
    </Info>
  </Step>

  <Step title="Add a product">
    Add your first product to the shop's catalog. Replace `{shop_id}` with the `id` value from the previous step.

    <CodeGroup>
      ```bash curl
      curl -X POST https://api.mutasib.com/api/v1/shops/shop_01j9xkz3p4qr5t6uvw7yz8abc/products/ \
        -H "Content-Type: application/json" \
        -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
        -d '{
          "name": "Organic Apples (1 kg)",
          "price": 12.50,
          "stock": 200
        }'
      ```

      ```python Python
      import requests

      shop_id = "shop_01j9xkz3p4qr5t6uvw7yz8abc"
      headers = {
          "Authorization": "Bearer YOUR_ACCESS_TOKEN",
          "Content-Type": "application/json",
      }
      payload = {
          "name": "Organic Apples (1 kg)",
          "price": 12.50,
          "stock": 200,
      }
      response = requests.post(
          f"https://api.mutasib.com/api/v1/shops/{shop_id}/products/",
          json=payload,
          headers=headers,
      )
      print(response.json())
      ```

      ```js JavaScript
      const shopId = "shop_01j9xkz3p4qr5t6uvw7yz8abc";
      const response = await fetch(
        `https://api.mutasib.com/api/v1/shops/${shopId}/products/`,
        {
          method: "POST",
          headers: {
            "Content-Type": "application/json",
            Authorization: "Bearer YOUR_ACCESS_TOKEN",
          },
          body: JSON.stringify({
            name: "Organic Apples (1 kg)",
            price: 12.5,
            stock: 200,
          }),
        }
      );
      const data = await response.json();
      console.log(data);
      ```
    </CodeGroup>

    ```json
    {
      "id": "prod_01j9xkz3p4qr5t6uvw7yz8def",
      "shop_id": "shop_01j9xkz3p4qr5t6uvw7yz8abc",
      "name": "Organic Apples (1 kg)",
      "price": 12.50,
      "stock": 200,
      "is_active": true,
      "created_at": "2024-11-01T10:05:00Z",
      "updated_at": "2024-11-01T10:05:00Z"
    }
    ```

    Note the `id` of the product — you need it in the next step.
  </Step>

  <Step title="Record a sale">
    Record a point-of-sale transaction by posting to the shop's sales endpoint. Pass an array of `items`, each with a `product_id` and `quantity`. Mutasib automatically decrements stock and issues a receipt token.

    <CodeGroup>
      ```bash curl
      curl -X POST https://api.mutasib.com/api/v1/shops/shop_01j9xkz3p4qr5t6uvw7yz8abc/sales/ \
        -H "Content-Type: application/json" \
        -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
        -d '{
          "items": [
            {
              "product_id": "prod_01j9xkz3p4qr5t6uvw7yz8def",
              "quantity": 3
            }
          ]
        }'
      ```

      ```python Python
      import requests

      shop_id = "shop_01j9xkz3p4qr5t6uvw7yz8abc"
      headers = {
          "Authorization": "Bearer YOUR_ACCESS_TOKEN",
          "Content-Type": "application/json",
      }
      payload = {
          "items": [
              {
                  "product_id": "prod_01j9xkz3p4qr5t6uvw7yz8def",
                  "quantity": 3,
              }
          ]
      }
      response = requests.post(
          f"https://api.mutasib.com/api/v1/shops/{shop_id}/sales/",
          json=payload,
          headers=headers,
      )
      print(response.json())
      ```

      ```js JavaScript
      const shopId = "shop_01j9xkz3p4qr5t6uvw7yz8abc";
      const response = await fetch(
        `https://api.mutasib.com/api/v1/shops/${shopId}/sales/`,
        {
          method: "POST",
          headers: {
            "Content-Type": "application/json",
            Authorization: "Bearer YOUR_ACCESS_TOKEN",
          },
          body: JSON.stringify({
            items: [
              {
                product_id: "prod_01j9xkz3p4qr5t6uvw7yz8def",
                quantity: 3,
              },
            ],
          }),
        }
      );
      const data = await response.json();
      console.log(data);
      ```
    </CodeGroup>

    ```json
    {
      "id": "sale_01j9xkz3p4qr5t6uvw7yz8ghi",
      "shop_id": "shop_01j9xkz3p4qr5t6uvw7yz8abc",
      "total": 37.50,
      "receipt_token": "rcpt_a1b2c3d4e5f6",
      "items": [
        {
          "product_id": "prod_01j9xkz3p4qr5t6uvw7yz8def",
          "product_name": "Organic Apples (1 kg)",
          "quantity": 3,
          "unit_price": 12.50,
          "subtotal": 37.50
        }
      ],
      "created_at": "2024-11-01T10:10:00Z"
    }
    ```

    The `receipt_token` uniquely identifies this transaction and can be shared with the customer or printed on a physical receipt.
  </Step>
</Steps>

<Note>
  Your access token expires after a short window. When you receive a `401 Unauthorized` response, call `POST /api/v1/auth/refresh` with your refresh token in the request body to obtain a new token pair:

  ```bash
  curl -X POST https://api.mutasib.com/api/v1/auth/refresh \
    -H "Content-Type: application/json" \
    -d '{"refresh": "YOUR_REFRESH_TOKEN"}'
  ```

  Store tokens in environment variables or a secrets manager — never hard-code them in your source code.
</Note>
